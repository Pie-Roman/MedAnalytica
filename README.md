## Описание проекта

MedAnalytica — это Android-приложение для медицинской аналитики, которое позволяет пользователям отслеживать и анализировать свои медицинские данные. Приложение предоставляет удобный интерфейс для просмотра результатов анализов, визуализации данных в виде графиков и управления медицинской информацией.

## Особенности проекта

- **Современный UI**: Приложение разработано с использованием Jetpack Compose и Material3, что обеспечивает современный и удобный пользовательский интерфейс
- **Визуализация данных**: Графическое представление медицинских данных для более наглядного анализа
- **Многослойная архитектура**: Четкое разделение на слои и модули для улучшения поддерживаемости и тестируемости кода
- **Безопасность**: Надежная система аутентификации и авторизации для защиты конфиденциальных медицинских данных

## Архитектура

Приложение построено с использованием многослойной архитектуры:

### Слои приложения:
1. **Presentation Layer (Слой представления)**
   - Отвечает за отображение информации и взаимодействие с пользователем
   - Включает UI компоненты и ViewModel-и

2. **Domain Layer (Слой бизнес-логики)**
   - Содержит бизнес-правила и логику приложения
   - Включает use cases и интерфейсы репозиториев

3. **Data Layer (Слой данных)**
   - Отвечает за работу с данными (сетевые запросы, кэширование)
   - Включает реализации репозиториев и источники данных

### Ключевые модули:
- **app**: Основной модуль приложения, содержащий MainActivity и настройки приложения
- **feature**: Модуль с функциональными экранами (авторизация, регистрация, профиль, анализы)
- **domain**: Модуль с бизнес-логикой и доменными моделями
- **data**: Модуль для работы с данными и сетевыми запросами
- **common**: Модуль с общими компонентами и утилитами
- **base/uikit**: Модуль с базовыми UI компонентами

## Функциональность

Приложение предоставляет следующие возможности:

1. **Авторизация и регистрация**
   - Вход в существующий аккаунт
   - Создание нового аккаунта

2. **Профиль пользователя**
   - Просмотр и редактирование личной информации
   - Управление настройками аккаунта

3. **Анализ медицинских данных**
   - Визуализация данных в виде графиков
   - Отслеживание динамики показателей

4. **Результаты анализов**
   - Просмотр результатов медицинских анализов
   - Сортировка и фильтрация данных

## Технологии и библиотеки

- **Kotlin**: Основной язык программирования
- **Jetpack Compose**: Для создания современного пользовательского интерфейса
- **Material3**: Для стилизации UI компонентов
- **Dagger/Hilt**: Для внедрения зависимостей
- **Coroutines**: Для асинхронного программирования
- **Jetpack Components**: ViewModel, Navigation
- **Retrofit**: Для сетевых запросов
